# LMC Galactic Winds

This repository contains supporting data products and fit diagnostics for the paper:

**“Tracing Winds through the Fog: A Comprehensive Survey of LMC's Galactic Outflows with ULLYSES”**  
Suraj Poudel et al.

The study uses ultraviolet absorption-line spectroscopy of 170 stellar sightlines across the Large Magellanic Cloud (LMC) to investigate the spatial and kinematic properties of gas associated with the LMC disk and galactic outflows.

## Repository Contents

### Data Tables

The repository contains the machine-readable tables associated with the analysis.

**Table 1**  
Properties of the 170 ULLYSES DR7 stellar sightlines used in the study, including sightline identifiers, Galactic coordinates, stellar spectral types, and available HST observing modes.

**Table 2**  
Voigt-profile fitting results for the absorption-line components detected along the 170 sightlines. The table includes the velocity boundaries adopted for the LMC disk, component velocities, column densities, Doppler parameters, and their associated uncertainties or limits.

### `Voigt_Fits_Figures/`

This directory contains Voigt-profile fitting figures for all **170 stellar sightlines** in the final sample.

Each figure shows the Voigt-profile fits to the metal absorption lines together with the corresponding H I 21-cm emission spectrum. These figures provide the fit diagnostics underlying the component measurements reported in Table 2.

### `Continuum_Fits_Figures/`

This directory contains **165 continuum-fit diagnostic figures** used in the analysis.

These figures illustrate the continuum normalization of the UV spectra prior to the absorption-line analysis. They are provided as supporting diagnostic material and are not intended to constitute a complete figure set for all 170 sightlines. Continuum-fit figures for a small number of sightlines are unavailable because of technical issues in generating the diagnostic plots.

## Notes

Sightline identifiers in the data tables and the Voigt-profile figure filenames correspond to the final 170-sightline sample used in the paper.

The continuum-fit figures are provided as additional analysis diagnostics, whereas the Voigt-profile figures correspond directly to the absorption-line measurements presented in the study.
